# Last Man Standing — CSV Viewer (Vite + React + Amplify)

Reads a CSV from CloudFront/S3 and shows a table per “game”.

## Quick start

```bash
npm i
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## AWS Amplify

- Run `amplify init` to initialize Amplify
- Run `amplify add hosting` then `amplify publish` to host
